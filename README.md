录音表与 oto 模板生成器

简介
这是一个用于 UTAU类声库录制 的辅助工具，能够根据自定义的发音规则文件自动生成：
录音表（reclist）：指导录音的发音序列。
oto.ini 配置：每个录音样本的别名、时间偏移、辅音长度、截断位置等参数。

支持多种录音模式（VCCV-CVVC、VCV、CVC、CV），提供丰富的生成选项，帮助音源制作者快速完成繁琐的配置工作。

功能特性
支持 VCCV-CVVC、VCV、CVC、CV 四种模式。
自动覆盖所有必要的发音组合，确保音源完整。
提供强制生成、开头音补全、尾音补全等保底机制。
可选的冗余剔除策略，优化录音表长度。
生成 oto 时自动去重，支持后备别名（#1、#2…）。
图形界面操作，实时预览生成结果。
支持多语言（当前内置中文，可通过 languages.ini 扩展）。
配置可保存/加载，便于复用。

系统要求
Python 3.6 或更高版本（推荐 3.8+）
依赖库：configparser、tkinter（Python 自带，无需额外安装）

使用指南

1. 准备规则文件
规则文件是一个 INI 格式的文本，描述每个音节的辅音、整音、过渡音和尾音。以下是一个简化示例（只展示核心音节）：

[RULE]

a=,a,,a

ai=,a',"_a'i",i~

ba=b,ba,,a

bai=b,ba',"_a'i",i~

ban=b,ba',"_a'n",n~

bo=b,bo,,o

bu=b,bu,,u

ca=c,ca,,a

cai=c,ca',"_a'i",i~

can=c,ca',"_a'n",n~

cuan=c,cu_,"_ua',_a'i",i~


每一行代表一个音节，键名是音节标识（如 ba）。
值包含四个字段，用逗号分隔：
1. 辅音（consonant）：音节开头的辅音，若没有则留空（如 a 行的第一个字段为空）。
2. 整音（onset）：音节的主要元音部分。
3. 过渡音（transition）：字内过渡音，可多个，用逗号分隔；如果该字段不为空，必须使用双引号包裹；若没有过渡音则留空（不加引号）。例如 "_a'i" 是单个音素，"_ua',_a'i" 是两个音素。
4. 尾音（coda）：音节的结尾音，用于连接下一个音节。

字段引号规则：
过渡音字段只要有音素，就必须加双引号，无论是一个还是多个。空过渡音字段直接留空，不加双引号。
辅音、整音、尾音字段通常不包含逗号，可以省略双引号；空字段留空即可。
示例中所有非空过渡音字段均已加双引号，请保持一致。

2. 启动程序并加载规则
点击“浏览…”选择规则文件。
根据需要调整设置参数（见下文）。
点击“生成”按钮，程序将生成录音表和 oto 配置。

3. 主要设置说明
录音模式：选择 VCCV-CVVC、VCV、CVC 或 CV。
最大音节数：每个录音条目包含的最大音节数量。
强制生成模式：选择不强制、重复、间隔、顺序，用于生成额外的强制条目。
开头音设置：决定开头音的类型（无、整音、辅音）。
确保尾音到 R：每个条目结尾是否添加 R 休止符（或 -）。
确保纯元音链接：生成纯元音之间的过渡音。
合并短条目：将短录音条目合并为较长条目，减少录音次数。
优先级选项：半元音或纯元音优先，影响生成顺序。
顺带生成：勾选后可额外生成尾音到辅音、尾音到整音等组合。

4. 查看结果
录音表 选项卡显示生成的录音条目列表。
oto 配置 选项卡显示对应的 oto 参数。
被剔除条目 显示因冗余而被移除的条目。
未使用的完整发音 显示规则中未被覆盖的音节。
诊断 显示生成日志和参数快照，便于调试。

5. 导出文件
点击“导出录音表”保存为 .txt 文件。
点击“导出 oto”保存为 .ini 文件，可直接用于 UTAU。
也可以按右下角的“复制全部”来复制到你的剪切板里。

配置说明
配置文件 reclistgen++_config.ini 保存了所有设置，可以通过界面“保存配置”生成，或手动编辑。

规则文件注意事项
确保每个音节的 onset 和 coda 字段不为空。
过渡音字段有内容时必须加双引号，空字段可不加引号。
辅音字段为空时，直接留空即可（如示例中的 a 行第一个字段）。

常见问题
Q：生成时提示“规则文件缺少 [RULE] 节”怎么办？
A：请检查规则文件是否包含 [RULE] 节头。

Q：某些发音未出现在录音表中？
A：检查“录音表冗余模式”和“保护”设置，确保没有过度剔除。也可以开启“确保全局完整发音完整”。

Q：oto 时间参数不合适？
A：可以调整 BPM 和前导静音，重新生成。如需微调，可手动编辑 oto 文件。
